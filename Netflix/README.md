
# Netflix

Netflix allows users to download the personal data associated with their accounts.  
To request your Netflix data, follow these steps:

1. Go to **Settings**.
2. Navigate to **Security → Personal info access**.
3. Click **Request**.
4. Confirm the request using the verification email sent to your registered email address.

Netflix will notify you by email when your data is ready for download.

When requesting a copy of Netflix users data, it is delivered as a ZIP file. Inside the ZIP file, the data is organized into multiple CSV files, with each file capturing a different aspect of your account activity and usage history.

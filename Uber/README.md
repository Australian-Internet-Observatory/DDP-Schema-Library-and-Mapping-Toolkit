# Uber
Uber allows users to download the personal data collected from their accounts. Depending on how the user has interacted with Uber, the data may include:

- Personal information  
- Rider data  
- Driver and delivery data  

To download your Uber data, follow these steps:

1. Go to the **Uber login page**: [https://auth.uber.com/v2/](https://auth.uber.com/v2/).
2. Log in to your profile.
3. Click **Download**.
4. Select **Request Your Data**.

Uber will send a notification to your registered email address when the file is ready.  
The data is delivered as **CSV files**, organized into different folders.

## Summary of Data Available Through Uber’s DDP

| Data Category           | Description                                                            |
|-------------------------|------------------------------------------------------------------------|
| **Account and Profile** | Information about the user, saved locations, and payment methods.      |
| **Rider**               | Information about the trips the user has taken.                        |

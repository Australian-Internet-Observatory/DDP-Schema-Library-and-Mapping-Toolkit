
# TikTok

TikTok allows users to access and download the data associated with their accounts. To request a copy of your data, follow these steps:

1. Go to **Profile**.
2. Select **Manage Account**.
3. Tap **Download TikTok Data**.

Users can choose between two types of downloads:

- **All Data:**
Includes all available information linked to the user account.

- **Custom Files:**
Allows users to select specific data categories, such as:

  - **Profile and Posts**  
  Personal information, follower list, accounts followed, and user posts.

  - **Activity**  
  Likes, comments, favorites, and browsing history.

  - **Messages**  
  Direct messages sent and received.

Further details on TikTok data types can be found here:   **[TikTok Data Portability](https://developers.tiktok.com/doc/data-portability-data-types/)**

TikTok DDP allows users to download their data either as a ZIP file (containing multiple folders and files if the data is downloaded in (.txt) format) or as a single (JSON) file if the .json format is selected.

# X 
Users on X can request a **ZIP file** containing an archive of their account information, account history, apps and devices, account activity, interests, and ads data.

## How to Download Your X Account Data

To download your data from X, follow these steps:

1. Go to **Settings**.
2. Click **Your Account**.
3. Select **Download an archive of your data**.
4. Click **Request Your Data**.

You will receive an **in-app notification** when your data archive is ready for download.

For more details on the types of data provided, refer to **[X Data Download (DDP) Guide](https://help.x.com/en/managing-your-account/accessing-your-x-data)**

The account data is downloaded as a **ZIP file** that includes multiple **HTML** and **JSON** files.  
A `README` file is also included, explaining the structure of the archive, the meaning of each file, and how to access or interpret the data.

### HTML Files

These files can be viewed in any desktop web browser.  They provide a rendered summary of key account information, including:

- Account information  
- Tweets  
- Likes  
- Messages  
- Personalized data  
- Ads information  
- And more


### Data Folders (JS Format)

These folders contain structured, detailed data from the user’s account, such as:

- Profile information  
- Tweets  
- Direct messages  
- Moments  
- Media (images, videos, GIFs) shared in tweets or messages  
- Followers and following lists  
- Address book  
- Lists (created, followed, or subscribed)  
- Inferred interests and demographic information  
- Ads viewed or interacted with  
- Additional metadata

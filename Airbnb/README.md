# Airbnb

Airbnb allows users to download a copy of the personal data associated with their accounts.  
To request your Airbnb data, follow these steps:

1. Go to **Account Settings**.
2. Navigate to the **Privacy** tab.
3. Select **Request My Personal Data** under the **Data Privacy** section.

Before downloading the data, users must:

- Select their **country of residence**.
- Choose their preferred **data format** (HTML, JSON, or Excel).

To confirm the request, Airbnb sends a **verification code** to the mobile number linked to the account.  
Once the data is processed, Airbnb sends an email notifying the user that the data is ready.  
The downloaded file is provided in **.zip format**.

---

## Summary of data available through Airbnb DDP.

| Data Category                         | Description                                                                                                                                                                                                 |
|---------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Profile Information**               | Summary of private and public profile details, including legal name, gender, date of birth, email, phone number, emergency contacts, and other personal information.                                        |
| **Account Information and Interactions** | Includes search history, reservations, activity log, account security information, report history, wishlists, messages, and reviews.                                                                        |
| **Payments & Financial Information**   | Covers payment history, payment instruments, chargebacks, payment administration, asset ledger, gift card usage, payment processing, and payment receipts.                                                 |

# Spotify

## Downloading Your Data from Spotify

Spotify allows users to request a copy of their account data through the **Download Your Data** tool. Users can request any of the three available data packages, either individually or all at once.

To request your Spotify data, follow these steps:

1. Log in to your **Spotify** account.
2. Navigate to **Account Settings → Privacy Settings → Download Your Data**.
3. Select the data package(s) you want to request.
4. Submit the request.

For more information about what is included in each package, see **“[Spotify data](https://support.spotify.com/au/article/understanding-my-data/#_gl=1*pj1dbk*_gcl_au*NTU3NzIyNjM0LjE3NTMyMzM1NTE.)”**

Spotify may take **5 to 30 days** to prepare the data, depending on the package.  
Once ready, users have **14 days** to download the file before the link expires.
The download data from Spotify account is a (zip) file that includes multiple json files.

##  Summary of data available through Spotify DDP.

| Data Category               | Description                                                                                                                                                       |
|-----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Account and Profile**     | Includes playlists, streaming history, saved content, search queries, follow lists, account information, and plan details.                                        |
| **Extended Streaming History** | A detailed list of items (songs, videos, podcasts) listened to or watched over the lifetime of the account.                                                      |
| **Technical Log Information**  | Contains technical data such as commands, error messages, and log strings collected for service delivery and troubleshooting.                                   |
